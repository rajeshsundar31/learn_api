# FastAPI Backend Learning Project

A backend project built with **FastAPI** and **Python** while learning backend development from scratch.

## What I Learned

- **CRUD Operations**: Create, Read, Update, and Delete endpoints
- **Authentication**: Login system with secure password hashing and JWT tokens
- **Authorization**: Role-based access control to protect routes
- **PostgreSQL Integration**: Connected the backend to a PostgreSQL database
- **Testing**: Wrote automated tests for the API endpoints

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy (if you used it)
- Pytest (if you used it)

## Features

- User registration and login
- JWT-based authentication
- Protected routes with authorization
- Full CRUD for [your resource, e.g. posts/products]
- Database persistence with PostgreSQL
- Unit and integration tests

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/rajeshsundar31/learn_api.git
   cd your-repo
   ```

2. Create a virtual environment and install dependencies
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
